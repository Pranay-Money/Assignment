# Day 9–11 - PHP Authentication System

A complete user authentication system built using PHP and MySQL, featuring user registration, login, role-based dashboards, and profile management.

## Features

- User Registration
- User Login & Logout
- Session Management
- Role-Based Authentication
- User Dashboard
- Head Admin Dashboard
- Update Profile
- Change Password
- About & Contact Pages
- Reusable Header & Footer
- MySQL Database Integration

## Topics Covered

- PHP
- MySQL
- CRUD Operations
- Sessions
- Form Validation
- Role-Based Access Control (RBAC)
- Bootstrap Components
- Modular PHP (`require_once`)
